- 记录按行动/图鉴切换并分页；行动详情分摘要/任务/调整时间线；发现展示真实自然周数据；我的保留授权、保留规则和有二次确认的删除。

- 宽屏一屏目标以 1024×768、1280×720、1440×900 验收；较小视口/缩放时以可访问性优先。每个正式页面及成功/异常状态都需浏览器复验。

## 第一版实现记录（需按上述修订优化）

- 保留单一代码库与数据/状态逻辑，新增只在 H5 加载的样式，桌面布局断点为 1024 CSS px。不覆盖用户已有小程序改动。
- 桌面固定 Taro rem 换算基准，避免所有元素随宽屏等比膨胀；桌面使用稳定字号和最大内容宽度，手机维持原换算。
- 首页：左侧完整品牌与角色，右侧输入/进行中任务，下方横向怪兽示例。增加正常布局容器，避免绝对定位占位不足。

- 记录、发现、我的沿用已有页面，调整电脑内容宽度与网格；有底栏的页面保持 TabPageLayout 和固定底栏，桌面底栏呈居中玻璃导航。
