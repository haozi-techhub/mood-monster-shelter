# Web 朋友内测版 — 技术计划

状态：Draft。依赖 [需求规格](spec.md) 评审；本文不是已实现能力清单。

## 1. 选择与现状

推荐沿用 **Taro 4.2 + React 18 + TypeScript + Less + CloudBase**，补齐现有 H5。Web 是本次交付端，小程序代码和构建保留；不切换 Next.js，也不创建另一套业务逻辑。

理由：本次目标是给朋友实际使用；已有 H5 插件、9 个页面、状态机、素材和测试。复用能集中解决真实模型访问、浏览器体验和发布安全。代价是必须处理 Taro 的端差异，不能把“构建通过”等同“浏览器完整可用”。

2026-08-26 静态检查事实：

- `package.json` 已有 H5 与微信构建和单元测试命令。
- `src/app.ts`、`src/services/agentApi.ts`、`monsterApi.ts` 依赖 `Taro.cloud`；当前安装的 H5 运行库未提供可用的该云调用实现。
- `runActionAgent` 的模型只改写 `reply`；当前入参/出参校验、超时控制、来源标识与公网限额需要补齐。
- 图片保存 API 在当前 H5 依赖中已有浏览器下载实现，不应误判为完全不支持；仍须验证手机浏览器的真实下载/预览结果。
- `analytics.ts` 是本地事件队列，没有集中采集后台。
- 已存在用户未提交的页面与样式修改；实施不得覆盖或回退。

## 2. 系统与数据流

浏览器 H5 → 内测访问校验 → CloudBase 受保护的 Web 调用入口 → 复用 Agent 规则编排 → 模型文案生成 → 结构/内容校验 → 浏览器状态机 → 用户确认后计时/本地记忆。

- Web 使用 CloudBase 支持的 Web SDK 或 HTTPS 接入，不能直接复用小程序 `Taro.cloud`。在 T002 中用目标环境的认证与权限能力完成最小联通验证后固定其中一种；这是技术待决项，不承诺尚未验证的匿名权限。
- 小程序仍使用现有云函数通道；传输层返回统一结果，避免页面理解平台协议。
- 所有付费入口复用同一访问和限额检查；旧 `analyzeMood` 不得成为绕过入口。
- 浏览器只配置公开环境 ID/接口地址；模型 URL 与 Key 仅由服务端控制，不接受客户端自定义模型地址。
- 应用不在云端保存原始聊天。额度计数是独立的非内容数据，不属于跨设备对话同步。

## 3. 拟定接口契约

保留 `src/types/agent.ts` 中的 `AgentTurnRequest` / `AgentTurnResponse`。Web 传输增加版本和元数据，适配后再交给现有状态机。

```ts
type AgentTransportResult =
  | {
      ok: true
      data: AgentTurnResponse
      meta: {
        requestId: string
        source: 'model' | 'fallback' | 'safety'
        reason?: 'not_configured' | 'timeout' | 'provider_error' | 'invalid_output' | 'unsafe_output'
      }
    }
  | {
      ok: false
      error: {
        code: 'INVALID_REQUEST' | 'ACCESS_DENIED' | 'RATE_LIMITED' | 'UNAVAILABLE'
        retryAfterSeconds?: number
      }
      requestId: string
    }
```

这是待实施契约，当前代码尚无该类型。若采用 HTTP，参数错误/未授权/超额/服务不可用分别使用 400/401 或 403/429/503；SDK 通道映射为相同错误码。

- 调用前验证 JSON 对象、请求体大小、字段类型、阶段/槽位枚举、200 字输入边界、上下文条数和总长度；超限明确拒绝，不静默裁掉高风险输入尾部。
- 安全校验覆盖所有可能影响模型的文本；客户端与服务端都执行，不能只信任客户端状态。
- 模型结果按明确 Schema 校验，并检查内容与规则决策一致；不安全、额外指令或无效结果不直接渲染。
- 元数据只能由服务端或本地适配器生成；不采信模型自报的 `source`。
- 远程失败保留当前会话，提示后可使用基础模式；重复点击禁用提交，迟到的旧响应不可覆盖新状态。
- 时限建议：模型单次 10 秒，云端整体 22 秒，浏览器 25 秒；重试最多一次且在总时限内，取消/超时后终止可取消的上游请求。

## 4. 内测访问、成本与配置

建议内测口令由服务器验证，交换短期访问凭据；具体凭据形式和有效期在 T002 结合实际通道确认。不把口令打包进网页、放进分享 URL 或当作模型 Key。浏览器匿名标识只是限额辅助，不是可靠的个人身份。

- 对口令尝试与模型调用分别限制频率；验证不通过不能触发模型。
- 额度由云端持久化并以原子方式预留；不能只用进程内 Map 或浏览器计数。模型重试也占额度。
- 同时限制单访问凭据、单时间窗口和整个环境的每日上游调用数；清本地数据或更换匿名身份不能绕过环境总额。
- CORS/域名白名单不是认证；直接 HTTP 请求也必须校验权限。
- 配置缺失默认关闭云模型；每日调用硬上限必须显式配置，未获预算确认不对外开放付费调用。
- 金额预算需结合所选模型价格、输入输出上限与云资源计费确定；云平台预算提醒不能代替服务端拒绝调用的硬限制。
- 模型或云资源达到限制时停止相应远程能力，保留可解释的基础模式；提供负责人可操作的停用开关。

环境项（仅变量名，不含真实值）：

| 项 | 位置与用途 |
|---|---|
| `MODEL_API_URL` / `MODEL_API_KEY` / `MODEL_NAME` | CloudBase 云函数环境；地址和响应协议需适配验证 |
| 内测凭据配置 | 服务端密钥管理；变量名与认证实现一起固定 |
| 每日全局额度、访问频率、云模型开关 | 服务端显式配置，缺省不开放付费访问 |
| CloudBase 环境 ID / Web 入口 | 前端可公开配置；不得包含任何模型凭据 |

开发示例只用占位符；本地敏感配置放已忽略文件。打包必须采用公开配置白名单，不把整个环境变量对象注入前端。

## 5. 隐私与浏览器体验

- 云端处理说明与本地记忆授权分离；关闭记忆后不带入跨会话数据。沿用 14 天会话、长期无原话摘要、30 分钟分享草稿。
- 分享卡、技术日志、错误提示不暴露聊天原话或模型请求体；额度记录只存必要的标识摘要/计数/窗口，保留期在认证方案固定时明确。
- H5 不调用微信胶囊与小程序云初始化；宽屏限制内容宽度，导航仍复用 `TabPageLayout`，不重做桌面工作台。
- 检验软键盘、视口高度变化、浏览器前进后退/刷新、后台返回与本地存储不可用；存储失败提示不阻止可进行的单次体验。
- 分享优先复用已有 Canvas；无法确认落盘时表述为“已发起下载”或提供预览，不能宣称已存入相册。
- 实施 UI 变化时同步视觉基线的 Web 规则与截图，不在本草案里提前标记其已生效。

## 6. 测试、发布与回滚

先运行已有 typecheck、Agent/客户端测试、H5/微信构建，再按 [验收清单](acceptance.md) 补入参、模型成功/失败、安全、限流并发和浏览器回归。优先扩展现有测试；只有 Web 传输/访问保护无自然归属时新增测试文件。

发布前固定前后端版本、接口契约版本、实际域名、环境、配额与关闭方法。接口变化兼容尚未更新的浏览器资源；缓存策略需保证页面不会长期引用失效的旧资源。

真实模型联调至少包含一条成功回应与一条受控失败；只留来源标记、请求 ID、耗时和状态等证据，不留敏感输入。目标设备与网络以实际测试结果为准。

回滚：优先关闭模型调用阻止继续消费；必要时恢复上一版前端和兼容后端，不删除用户本地记录。仅规则模式可以演示，但不能作为本规格的真实 AI 交付通过。
